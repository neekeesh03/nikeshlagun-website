# nikeshlagun.com.np

Static site (plain HTML, CSS, JS). Palette: #40734D, #D98B48, #C7D9CC, #696866, #B7A7D9, #F2F2F2.

- Open `index.html`, or serve the folder: `python3 -m http.server 8765`
- Newsletter and waitlist forms go to https://nikeshlagun.substack.com/subscribe
- Contact form opens an email to lagunnikesh2064@gmail.com
- Edit the sticker note text: `STICKER_MSG` at the bottom of `js/main.js`
- `a/` holds the newsletter archive pages
- Album covers: drop square images into `img/albums/` named `timi-ra-ma.jpg`, `mayalu.jpg`, `ekasi-timi.jpg`, `bhagi-jaun.jpg`. They replace the placeholder art automatically.
